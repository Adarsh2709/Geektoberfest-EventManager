# Good first issue ideas

These are future contribution ideas. They are intentionally outside the initial MVP; check the issue tracker before starting so work is not duplicated.

1. Add event categories and let visitors filter by category.
2. Add sorting by event date, title, or number of open seats.
3. Add pagination to the event list and search results.
4. Add a dark color theme with a simple theme toggle.
5. Add an optional event cover image URL and display it on event cards.
6. Show attendee counts and remaining seats consistently on cards.
7. Add an upcoming/completed event status indicator.
8. Add event tags and allow visitors to search by tag.
9. Add a public organizer profile with their hosted events.
10. Add a copyable link and share action for event details.
11. Add an `.ics` calendar download for an event.
12. Improve the mobile layout and keyboard accessibility.
13. Add a location filter to event search.
14. Let organizers view the attendee list for their events.
15. Let organizers change event capacity while respecting current registrations.
