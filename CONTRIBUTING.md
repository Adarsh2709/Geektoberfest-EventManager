# Contributing to Event Hub

Thanks for helping make Event Hub better! Small fixes, documentation updates, and beginner-friendly improvements are all welcome. If you plan a larger change, open an issue first so we can agree on the approach.

## Your first pull request

1. **Fork** this repository on GitHub.
2. **Clone your fork** and enter the project directory:

   ```bash
   git clone https://github.com/YOUR-USERNAME/EventManager.git
   cd EventManager
   ```

3. **Create a branch** for your change:

   ```bash
   git switch -c fix/short-description
   ```

4. **Make your changes.** Keep the change focused and update the README if setup or behavior changes.
5. **Run the app locally** using the instructions in the README. Check the relevant flow in the browser or API docs.
6. **Commit your work** with a clear message:

   ```bash
   git add .
   git commit -m "Describe the change"
   ```

7. **Push your branch** to your fork:

   ```bash
   git push -u origin fix/short-description
   ```

8. **Open a pull request** from your branch to this repository's default branch. Describe what changed and how you checked it. Link any related issue.

Please don't commit `.env` files, passwords, or tokens. Be kind and constructive in issues and reviews.
